Portfolio Dashboard

One view of a Singapore portfolio split across ETFs, SGX blue chips, S-REITs and US stocks, instead of checking four places.

Context
Personal project
Year
2026
Stack
Python, Streamlit, pandas, Moomoo OpenD API

The problem

The portfolio spans four kinds of holding, and seeing all of it meant checking four places. I wanted a single view of the whole book.

What I built

  • A Streamlit dashboard that either reads a broker statement export or pulls positions live from the account through the Moomoo OpenD API.
  • All four asset classes in one view, with the data handled in pandas.

Prices you can trust

Live prices are not always available, so they fall back through three tiers: the broker feed, then an intraday quote, then the daily close.

Every row shows which tier priced it and how old the quote is. A dashboard that quietly shows a stale price as live is worse than one that tells you it is stale, so a delayed price is never mistaken for a live one.
